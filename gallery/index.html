Finished shelf · 78 pieces · updated November 2026

Finished pieces, kept together.

Every piece here is a complete, self-contained browser app you can lift out and run on its own — data desks and finance tables, small tools and sign-ins, product and editorial pages, 3D objects and spatial interactions, scenes and animations, games and toys. No shared package, no monorepo: a piece is a folder, its README, and the code it needs. The 24 early cuts, source cuts, prototypes, server-dependent demos and studies are in a separate Workshop, so they do not dilute the shelf.

Run a piece on its own

npm run install:piecesnpm run dev -- night-dialnpm run sitenpm run serve

Vite pieces build with a relative base; static pieces are copied as they are. Some static scenes load three.js from a CDN, so they need a network connection. Everything else is in the folder.

The Workshop keeps the other 24 — early cuts, source cuts, prototypes, server-dependent shelf cuts, alternate editions and single-technique studies. Same category taxonomy, separate room; nothing is deleted.

Pieces arrive as they were published, or recovered from a public deployment when no repository exists. All are kept with their credit intact; unless a piece says otherwise, no licence is granted beyond reading and learning. Six arrivals name their authors in their own READMEs: mrdoob's New York, Guillermo Rauch's record player, Will Eastcott's splat shop, Robin Payot's Codrops tutorial, Yuri Artiukh's eighteen Codevember days and curllmooha's twenty-three.

Linked arrival, not counted above: OpenVDB (Object / tool, own fork). Rain Alley’s film stays upstream; its source layer is in the Workshop.
