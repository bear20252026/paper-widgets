Why this room exists

A finished piece is the primary edition of a work, complete in the browser without a missing service. The workshop holds everything else: first passes, source cuts, prototypes, server-dependent shelf cuts, alternate editions and single-technique studies. The shelf holds 78 finished pieces; this room holds 24.

npm run install:piecesnpm run dev -- night-dialnpm run sitenpm run serve

Vite pieces build with a relative base; static pieces are copied as they are. Some static scenes load three.js from a CDN, so they need a network connection. Everything else is in the folder.

All pieces keep their credit. Unless a piece says otherwise, no licence is granted beyond reading and learning. The classification lives in gallery/catalog.json and CURATION.md.
