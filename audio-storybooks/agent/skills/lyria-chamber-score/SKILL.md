# Bespoke Instrumental Chamber Score Specification

Set `musicPrompt` in `./workspace/data/storybook.json` to describe a purely instrumental acoustic chamber recording tailored to the book's era and key signature (cello, contrabass, viola, fortepiano, harp, or woodwinds, rich `80–400 Hz` acoustic body, zero vocals, zero percussion). The host Studio Server synthesizes and mixes the chamber score beneath the mastered multi-voice narration automatically.
